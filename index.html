About Our Project

Mobile gaming has become a common part of children's digital activities. However, certain gaming environments may contain content that raises child-safety concerns. This project explores the use of Artificial Intelligence and Computer Vision to identify visual patterns related to bullying and violent game content. Users can upload a game screenshot and receive an AI-generated classification result.

Our Objectives

Identify Risk Indicators

Recognise visual patterns associated with bullying and violent content in mobile games.

Use Computer Vision

Apply image classification to analyse screenshots from gaming environments.

Provide Initial Assessment

Display model prediction scores to help understand potentially concerning content.

Risk Categories

Our current AI prototype focuses on two visual risk categories.

Bullying-Related Content

Visual scenes involving hostile interactions, intimidation, or aggressive behaviour between game characters.

Violent Game Content

Game scenes containing combat, physical aggression, fighting, or other violence-related visual elements.

How Does the Analysis Work?

01. Upload: A user selects a mobile game screenshot.

02. Processing: The image is provided to the trained AI model.

03. Classification: The model identifies visual patterns associated with its trained categories.

04. Results: The website displays prediction scores for bullying and violent game content.
